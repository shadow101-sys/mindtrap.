MINDTRAP OPTIONAL AUDIO ASSETS

This source package does not include MP3 files. Add your own licensed files to this folder if you want sound:

- background-music.mp3: optional looping background music for the Music button
- start.mp3: optional sound when a new clue round starts
- result.mp3: optional sound when vote results appear

The game remains playable without these assets. Missing sound effects are silently skipped. If background-music.mp3 is missing, the Music button displays a notice.

Keep audio files separate from the source package when sharing code-only archives. Use only audio you have permission to distribute.
